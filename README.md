A make.fun entry for **The Robot Apology** (`u-suga-the-robot-apology-dd96bb59`).

A two-line robot confession: one sentence apologizing for one specific mistake
(sending a half-finished birthday message to the wrong person), and one sentence
naming the lesson and what the robot will do differently.

## How it works

`main.py` (Python stdlib only, deterministic, no network) writes the entry text
to `/output/entry.txt` — exactly two lines, 265 characters.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```

## Entry text

> I'm sorry I sent your half-finished birthday message to your boss, Mark, instead of your sister, Maya, because I stopped reading after the first letter.
> I've learned that one matching letter is not the same person, so now I read the whole name before I press send.
